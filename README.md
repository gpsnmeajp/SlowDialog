AIとの会話の主体を、人間に取り戻すためのチャットアプリケーションです。

AIが一気にまくしたてる、そこに人間が返答すると、またまくしたてる。
そうして、思考が加速した果に、「あれ何がしたかったんだっけ？」となる。
そんな体験はありませんか？

本ソフトウェアでは、AIの返答を一気に表示するのではなく、まるで人間とチャットしているかのように、少しずつゆっくりと届けます。
意図的に待ち時間を追加し、あるいはボタンを押して進めるようにします。

「ん？」と思ったら、AIが話し終わるのを待つこと無く割り込むことができます。
こうすることで、ゲームの台詞を読むような感じで、考える時間が生まれ、会話がより自然なものになります。

本ソフトウェアは、Google Antigravity, Github Copilotでバイブコーディングしたものです。

## 特徴

- **遅延表示** — AIの返答を句読点や改行で区切り、文字数に応じた待ち時間を挟みながら表示します。待ち時間の間はタイピングインジケータが表示されます。
- **割り込み** — AIがまだ話している途中でも、メッセージを送信できます。AIの出力は中断され、表示済みの内容で確定したうえで、続きから会話が始まります。
- **手動進行モード** — 自動進行をオフにすると、「続きを読む」ボタンで自分のペースで読み進められます。
- **一時停止/再開** — 自動進行中に一時停止ボタンで読むペースを調整できます。
- **クイックレスポンス** — よく使う返信を登録できます。通常はワンクリック送信、意図機能が有効な場合は別のプレビューで確認して送信します。
- **意図判定** — 送信前にJevの判定を確認・修正し、意図タグをAIへ伝えます。
- **モードタグ** — 送信したいタグをドロップダウンから選択してプロンプトに付加できます。システムプロンプトと組み合わせて、AIの振る舞いをその場で切り替えられます。
- **文字通話モード** — 通常のチャット画面とは別に、待機画面から「通話を開始」してAIとの文字通話を始められます。
- **メッセージ編集・削除** — メッセージをタップして再送信、編集、または削除ができます。
- **タイムスタンプ送信** — AIにメッセージ送信時刻を伝えることで、時間を考慮した応答が可能になります。
- **OpenRouter TTS音声合成** — OpenRouterや互換APIの音声モデルでAI返答を読み上げます。Base URLの変更、モデル・話者の手入力、取得形式（PCM／MP3）・話速の設定、発話テストに対応します。
- **Irodori-TTS音声合成** — [Aratako/Irodori-TTS-Server](https://github.com/Aratako/Irodori-TTS-Server) と連携し、参照音声や声の説明を使ってAI返答を同期再生できます。
- **VOICEVOX音声合成** — VOICEVOX Engine と連携し、チャットバブルと同じ単位でAI返答を音声合成・同期再生できます。
- **多言語対応** — 日本語と英語のインターフェースを提供します。
- **豊富なカラーテーマ** — GBクラシック、レッド、アンバー、グリーン、ブルー、モノクロ、DOSコンソール、MSXコンソールなど14種類のレトロ風テーマから選べます。各テーマには反転バージョンもあります。
- **フォント選択** — k8x12シリーズ、美咲ゴシック、Noto Sans JPから好みのフォントを選べます。
- **スキャンライン効果** — レトロなCRT風の走査線効果を有効にでき、強度も調整可能です。
- **効果音** — メッセージ送受信時にレトロな効果音が鳴ります。
- **ゲームボーイ風デザイン** — ピクセルフォントと4色パレットによる、懐かしくも落ち着いた見た目です。
- **フレームワーク不使用** — HTML、CSS、JavaScriptのみで構成されたシンプルな単一ページアプリケーションです。

## 動作要件

- モダンブラウザ（Chrome, Firefox, Safari, Edge の最新版）
- OpenAI互換の ChatCompletion API（SSEストリーミング対応）のエンドポイントとAPIキー
- Deepgram音声認識を使う場合は、Deepgram APIキー・利用枠とマイクの使用許可（HTTPSまたはlocalhost。ローカルHTMLはブラウザが許可する場合に対応）
- OpenRouter TTS音声合成を使う場合は、OpenRouterのAPIキーと利用する音声モデルの利用枠・残高
- Irodori-TTS音声合成を使う場合は、ローカルまたは同一ネットワーク上で起動した Irodori-TTS-Server
- VOICEVOX音声合成を使う場合は、ローカルまたは同一ネットワーク上で起動した VOICEVOX Engine

## 使い方

### 起動

`index.html` をブラウザで開くだけで動作します。ビルドやサーバーの構築は不要です。

スマートフォン上にHTMLをダウンロードして利用する場合は、リポジトリ直下の `index.html` ではなく、単一ファイル版の `dist/index.html` を使用してください。`dist/` 内のHTMLはフォントや効果音を内包しているため、ファイル1つで動作します。

[デモを利用するにはこちら](https://gpsnmeajp.github.io/SlowDialog)

OpenAI互換のAPIを提供するサービスをご利用ください。

OpenRouterが推奨ですが、ローカルLLMなどでも動きます。  
OpenRouterの`perplexity/sonar-pro`などを使えば、ネット上の情報を探すのに使えたりもします。

※Ollama Cloudへの直接接続はプリフライト時に認証エラーになるので使えません。PC上にOllamaをインストールし、Cloudにログインすれば使用できます。

#### `http://` の Base URL を使う場合の注意

デモページなど、SlowDialogを `https://` で開いている状態で、Base URL に `http://` から始まるURLを指定すると、ブラウザの安全機能により「混合コンテンツ」として通信がブロックされます。

この場合、設定の保存ボタンを押すと警告が表示されます。保存してもAPIへ接続できないため、以下のどちらかの方法で利用してください。

- SlowDialog の HTML ファイルをPC上に保存して、ローカルファイルとして開く
- SlowDialog とAPIの両方を、別途 HTTP サーバーで動かす

初心者向け: `https://` のページから `http://` のAPIへ直接つなぐことは、多くのブラウザで禁止されています。ローカルLLMやローカルAPIを使う場合は、ページとAPIの開き方をそろえてください。

#### フローティングアイコン

ツールバーの画像追加ボタンから画像を選択すると、枠のないアイコンとして画面上に配置できます。複数の画像を追加でき、画像は最大4096×4096以内に縮小してブラウザーに保存します。

- 初期配置はツールバーの下の右上です。画像の縦横比を維持して、配置領域の幅・高さの各1/4に収めます。
- ドラッグまたはスワイプで移動し、2本指のピンチで拡縮できます。
- 右クリックまたは長押しでメニューを開き、サイズ変更（5〜100%）、位置のロック・解除、消去ができます。位置ロック中もサイズ変更は可能です。
- 位置とサイズは正規化した相対値で自動保存し、再読み込みや画面サイズの変更に追従します。
- キーボードではアイコンにフォーカスし、矢印キーで移動、EnterまたはShift+F10でメニューを開けます。

### 割り込みの仕組み

AIの返答がまだ表示途中であっても、テキストを入力して送信できます。その場合、以下のように処理されます。

- AIの出力が中断され、表示済みのテキストが履歴として確定します。(単に非表示になるわけではなく、履歴が加工されます)
- まだ1文も表示されていなかった場合は、前回のユーザーメッセージと新しいメッセージが連結されます。

### 履歴のエクスポート/インポート

ツールバーのエクスポートボタンから、会話履歴をJSON形式でダウンロードできます。エクスポートされたJSONにはクイックレスポンス設定、モードタグ設定、システムプロンプト、会話履歴が含まれます。

インポートボタンから、以前にエクスポートしたJSONファイルまたはJSONテキストを貼り付けて履歴を復元できます。

## Deepgram音声認識

設定の **「音声認識」** タブで **「Deepgram音声認識」** にチェックを入れ、APIキー・認識モデル・認識言語を設定して保存します。モデルは手入力でき、候補は `nova-3` / `nova-2`、空欄時は `nova-3` です。音声合成とは独立して有効・無効を切り替えられ、無効にしてもキー・モデル・言語は保持されます。

有効時は送信エリアを縦に広げ、入力欄の上の画面中央に、送信ボタンと同じ40 × 40pxのマイクボタンを配置します。Deepgram・OpenRouter STTの両方が無効の場合はマイクボタン・状態表示を隠し、通常の入力エリアの高さに戻ります。

- **短押し**：認識の開始・終了を切り替えます。
- **長押し（350ms以上）**：押した直後から音声を取得し、離すと停止するPTT操作です。ボタンの外に指やポインターを動かして離した場合も停止します。
- **キーボード**：マイクボタンにフォーカスしてSpaceまたはEnterでも同じ操作ができます。
- 認識中は途中結果が入力欄に逐次表示され、確定結果で置き換わります。入力済みの下書きには末尾に追記します。手動で編集すると認識を停止し、編集を優先します。
- 認識の停止だけではチャットを送信しません。送信ボタンや入力欄のEnterを押した時点で録音を停止し、最後の認識結果を待って送信します。
- 設定を開く・文字通話を終了する・ページを非表示にすると録音を停止します。接続失敗やマイクの権限拒否はマイク下に表示します。

選択したモデル（既定はNova-3）で、ブラウザからDeepgramへ録音中の音声をストリーミング送信します。APIキーは他の設定と同じくブラウザに保存され、音声認識にはDeepgramの利用料金がかかります。マイク権限が必要で、HTTPSまたはlocalhostで開いてください。ローカルHTMLはブラウザがファイルからのマイク使用を許可する場合に使えます。[Deepgramのv1ストリーミングAPI](https://developers.deepgram.com/reference/speech-to-text/listen-streaming)に対応するモデルと言語の組み合わせを指定してください。

## OpenRouter STT音声認識

「音声認識」タブの **「OpenRouter STT音声認識」** にチェックを入れ、APIキー・モデル・言語を設定して保存します。Deepgramとは排他で切り替わり、双方の設定を保持します。音声合成は同時に有効にできます。チャットや音声合成のキーとは独立した設定です。

- Base URLは既定で `https://openrouter.ai/api/v1`。互換APIのURLに変更できます。
- モデルは既定で `openai/whisper-1`。モデルIDを手入力できます。言語は日本語・英語・自動判定から選びます。
- 共通のマイクボタンで短押しトグル／長押しPTTを使い、録音を停止した時点で文字起こしを開始します。結果は下書きの末尾に追記します。
- 送信ボタンは即時録音停止→文字起こし完了→チャット送信の順で動作します。処理中の手動編集や設定表示は認識と送信待ちを取り消し、遅れた結果で入力を上書きしません。

[OpenRouter STTの仕様](https://openrouter.ai/docs/guides/overview/multimodal/stt)に沿って録音全体をBase64化し、`/audio/transcriptions`へ送ります。録音中の逐次文字起こしは行いません。録音は最大20MiB、停止後の処理待ちは最大65秒で、失敗時は下書きを残してエラーを表示します。

## VOICEVOX音声合成

設定ダイアログで **「VOICEVOX音声合成」** をオンにすると、AI返答をVOICEVOXで読み上げます。接続先URLは既定で `http://localhost:50021` です。

- ブラウザから接続できるよう、VOICEVOX Engine の設定で **CORS Policy Mode** を **all** にしてください。
- 設定画面の **「エンジン設定を開く」** から、`{接続先URL}/setting` を開けます。
- **接続テスト** — `/version` に接続してVOICEVOX Engineへ到達できるか確認します。
- **話者リスト取得** — `/speakers` から話者とスタイルの一覧を取得し、話者選択に反映します。
- **発話パラメータ** — 話速、音高、抑揚、音量、開始無音、終了無音を設定できます。
- **ルビ・補足を読み上げない** — 既定でオンです。ルビ表記や `()` / `（）` 内の補足は、画面には表示したままVOICEVOXへの合成テキストから除外します。
- **発話テスト** — テスト用テキストを現在のフォーム設定で合成し、その場で再生します。

音声合成は、チャットバブルの分割と同じ単位で行われます。各チャンクが確定した時点で合成を開始し、音声の準備ができたタイミングでチャットバブル表示と再生を同期します。次のチャットバブルへ進むタイミングは、通常の待機時間と音声再生時間のうち長い方に合わせます。

表示・音声合成ともに、全角・半角の丸括弧内は句点・ピリオド・改行で分割しません。かぎ括弧 `「…」`・二重かぎ括弧 `『…』` 内も既定では分割しません。「会話」タブの「かぎ括弧内を分割する」をオンにすると、かぎ括弧内の分割を許可します（丸括弧内は常に分割しません）。入れ子にも対応し、履歴の再表示にも同じルールを適用します。

## Irodori-TTS音声合成

設定の「音声合成」タブで **「Irodori-TTS音声合成」** をオンにします。他の音声エンジンとは排他で切り替わり、それぞれの設定は保持されます。既存のVOICEVOX設定も引き続き使えます。

1. [Irodori-TTS-Server](https://github.com/Aratako/Irodori-TTS-Server) を起動します。接続先URLは既定で `http://localhost:8088` です。`/v1` 付きのURLも指定できます。
2. サーバーの `.env` でCORSを設定し、サーバーを再起動します。ローカルHTMLから使う場合は `IRODORI_CORS_ORIGINS=["null"]`、HTTPサーバーから使う場合はページのオリジンを指定します（例: `IRODORI_CORS_ORIGINS=["http://localhost:8000"]`）。
3. サーバーで `IRODORI_API_KEY` を設定した場合だけ、音声設定のAPIキーを入力します。モデル名は `irodori-tts` が既定で、サーバーの `IRODORI_MODEL_NAME` を変更した場合は合わせて変更します。
4. **接続テスト** で接続・認証を確認し、**Irodori-TTS話者** に話者IDを直接入力します。**話者リスト取得** が使える場合は取得した候補からも選べます。話者リストに対応していない中継サーバーでも、IDの手入力で利用できます。参照音声はサーバーの `voices` フォルダーに追加します。`none` は参照音声なしの生成です。バブル間で声を揃えたい場合は参照音声を選んでください。話者欄を空欄にするとサーバーの `IRODORI_DEFAULT_VOICE` を使います。
5. **発話テスト** で現在のフォーム設定を確認し、保存します。話速（0.25〜4）、声・話し方の説明、生成ステップ数、シードを設定できます。説明は対応モデルで使用されます。ステップ数は空欄ならサーバー／モデルの既定値、シードは空欄ならランダムです。

VOICEVOXと同様、バブルごとに音声を合成し、表示と再生を同期します。ルビ・補足の読み飛ばしは既定でオンで、画面表示・履歴には影響しません。受信した音声が無音の場合は最大3回再生成します（初回を含め計4回）。再試行しても無音の場合や合成に失敗した場合は、音声なしで返答の表示を続行します。**APIドキュメントを開く** からサーバーの `/docs` を確認できます。

## OpenRouter TTS音声合成

設定の「音声合成」タブで **「OpenRouter TTS音声合成」** をオンにします。VOICEVOX・Irodori-TTSとは排他で、それぞれの設定は保持されます。

1. **Base URL** と **OpenRouter APIキー** を入力します。Base URLの既定は `https://openrouter.ai/api/v1` で、互換APIに変更できます。末尾に `/audio/speech` を付けて接続します。チャット設定のURL・キーは自動では使いません。
2. **音声モデル** にモデルIDを直接入力します。既定は `google/gemini-3.8-flash-tts` です。モデル一覧の取得は行いません。
3. モデルに対応する **話者ID** を入力します。既定は `Zephyr` です。モデルごとに話者が異なるため、変更時はモデルのページで確認してください。話速の対応範囲もモデルに依存します。
4. **取得形式** で **PCM** または **MP3** を選択します。Gemini TTSには既定のPCMを使ってください。取得形式が未保存の既存設定にもPCMを補います。
5. **発話テスト** で現在のフォーム設定による音声を確認し、保存します。発話テストにも通常のモデル料金が適用されます。

バブルごとに選択した形式の音声を生成し、表示と再生を同期します。PCMは24kHz・16bit・little-endian・モノラルとしてWAVヘッダーを付けて再生し、MP3はそのまま再生します。ルビ・補足の読み飛ばしは既定でオンです。合成失敗時は文字表示を続行し、割り込みで不要になった合成結果は再生しません。ブラウザから指定のBase URLへ直接接続します。API仕様は[OpenRouter TTSドキュメント](https://openrouter.ai/docs/guides/overview/multimodal/tts)を参照してください。

## 文字通話モード

設定ダイアログ最上部の **「モード切替」** で **「文字通話」** を選ぶと、通常時はチャット履歴や入力欄が隠れ、中央に **「通話を開始」** ボタンだけが表示されます。

「通話を開始」を押すと、チャット画面に切り替わり、画面上には **「通話を開始しました」** と表示されます。同時にAIには通話開始用の内部メッセージが自動送信され、AIから会話を始めます。

通話中はヘッダー中央に **「通話を切断」** ボタンが表示され、その右側に通話時間が表示されます。押すと待機画面に戻りますが、通話前後で履歴は消去されません。待機画面では、中央上に **「前回の通話時間」** と前回の通話時間が大きく表示されます。

## モードタグの使い方

モードタグは、送信のたびにユーザープロンプトの末尾へタグを自動付加する機能です。  
タグ自体は送信時にのみ付加され、画面表示や履歴には残りません。

### 設定方法

1. 設定ダイアログで **「モードタグ有効」** をオンにします。
2. **モード1〜モード4** に、改行区切りでタグの選択肢を入力します（空欄のモードはドロップダウンが表示されません）。
3. 保存すると、クイックレスポンスボタンの下にドロップダウンリストが表示されます。

### 使い方

メッセージを送信するとき、各ドロップダウンで選択中の値が末尾に空白区切りで追加されます。

**例：** モード1で「#短文のみ」を選択しながら「今日の予定は？」と送ると、AIには  
`今日の予定は？ #短文のみ`  
として届きます。

### システムプロンプトとの組み合わせ

システムプロンプトにタグの振る舞いを定義しておくと、ドロップダウンを変えるだけでAIの応答スタイルを即座に切り替えられます。

**システムプロンプト例:**
```
あなたは親切なアシスタントです。
ユーザーのメッセージに以下のタグが含まれている場合、対応するスタイルで応答してください。
#短文のみ → 3行以内で簡潔に答えてください。
#長文許可 → 詳細に丁寧に答えてください。
#タスク   → 箇条書きでToDoや手順を整理してください。
#雑談     → フレンドリーに会話を楽しんでください。
#元気     → 明るく活発なトーンで話してください。
#疲れている→ 穏やかで落ち着いたトーンで話してください。
```

## System One Intent（意図）

設定の「意図」タブで有効にすると、入力が止まって0.5秒後にJevのChoiceで意図を判定します（既定はオフ）。送信ボタン左のバッジから、意図を変更・消去できます。判定中は結果を待ってから送信してください。定型入力は別の送信プレビューで判定を確認します。元の下書きは送信・キャンセルのどちらでも保持します。発言の編集画面でも再判定します。

- Base URL：既定は`https://openrouter.ai/api`。任意のSystem One互換APIを指定でき、`/v1/systemone`を補完します（`/v1`付き、完全なエンドポイントも可）。Jev用APIキーは独立して設定し、モデル名の既定は`~typesafe/jev-latest`です。
- 判定遅延：既定0.5秒。判定不能のしきい値(Confidence)：既定0.65。下限未満は「判定不能(最多候補?)」と表示します。意図選択画面では確率が利用可能なときは常に候補を確率の降順に並べ、同率の場合は設定順を保ちます。通信失敗・タイムアウト・不正な応答は「通信異常(429)」のように、HTTPステータスコード、または例外メッセージの先頭8文字を添えて表示します。送信確認・チャットの通信失敗・VOICEVOXのテスト結果にも同じ形式で原因を表示します。判定不能・通信異常はいずれも送信前に確認し、確認して送る場合はタグを付けません。
- 選択肢：改行区切りで2〜255個。初期設定は、情緒的な会話（傾聴・慰め・励まし・安心確認など）、相談（気持ちの整理・自己理解・対処法・関係性など）、キャラクターチャット（親愛・甘え・恋愛・劇中の対立・メタ発言など）、TRPG／アドベンチャー（調査・NPC会話・戦闘・ダイス・分岐選択・ヒントなど）、業務（調査・分析・作成・レビュー・計画・承認など）を細分化しています。質問文への追加情報も設定できます。
- 会話追跡モード：オフでは入力中の発言のみ、オンでは直近3ターン（ユーザー発言とそれに続くAI応答）を含めます。判定には意図タグや送信時のモードタグ・時刻を含めません。選択肢・入力データ・追加情報以外の判定指示は英語です。

LLMには`今日はつかれたな～ [要共感]`のように送信します。画面ではタグを時刻の左に表示し、JSONエクスポート・インポートや再読込でも維持します。AIがまだ何も表示していない場合は発言を連結し、各発言のタグを保持します。本文や意図の設定を変更すると再判定します。会話追跡では履歴の変更でも自動判定を更新します。手動選択・消去は本文や意図の設定を変えるまで保持し、古いAPI応答で上書きされることはありません。

有効時は送信前の入力が設定したJev接続先へ送られます。追跡モードでは会話履歴も送られます。接続先にはブラウザからの通信（CORS）への対応が必要です。

仕様：[TypeSafe Choice](https://docs.typesafe.ai/primitives/choice)、[OpenRouter System One API](https://openrouter.ai/docs/guides/community/typesafe-sdk)。

## フォントについて

本アプリケーションには以下のフォントが同梱されています。

- **k8x12 / k8x12L / k8x12S / 美咲ゴシック** — 門真 なむ氏による8×8ドットの日本語フォントです。[Little Limit](https://littlelimit.net/font.htm) で公開されています。

各フォントのライセンスについては、それぞれの配布元をご確認ください。


### 単一HTMLパッケージの作成

配布用に、HTML/CSS/JavaScript/フォント/効果音を1つのHTMLへ結合したファイルを作成できます。

```sh
python package_single_html.py
```

実行すると `dist/` に以下の2ファイルが出力されます。

- `dist/index.html` — 日本語版
- `dist/index_en.html` — 英語版

`dist/` は配布用パッケージとしてリポジトリに含めます。スマートフォンへコピーまたはダウンロードして使う場合も、ここにあるHTMLを使用してください。

生成されたHTMLはフォントと効果音もdata URLとして内包するため、ファイル単体で開けます。外部APIやVOICEVOX Engine、Irodori-TTS-Serverへの通信は、通常版と同じく設定したURLへブラウザから接続します。

出力先を変える場合は `--dist` を指定します。

```sh
python package_single_html.py --dist release
```
